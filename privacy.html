Privacy

Short version: your tests stay on your computer.

The app

  • No account. You never sign up or sign in to use APITestCenter.
  • Usage counts only if you say yes. The app asks once. If you agree, once a day it sends: a random install number, the app version, your operating system, and four counts — requests sent, load tests run, compares, imports. Never URLs, request or response contents, results, names, tokens, or anything you type. Help shows the exact data before it is sent, and turns it off any time. If you say no, nothing is sent, the app stops counting, and any counts it had kept on your computer are deleted.
  • Update checks. The app asks GitHub whether a newer version exists, a few times a day. That request carries no information about you or your tests.
  • Requests go only where you send them. When you press Send or run a load test, traffic goes from your computer straight to the API you entered — never through our servers.
  • Results are files you own. Runs, compares, and saved requests are plain JSON files in your app-data folder (on Windows, %APPDATA%\ApiTestCenter). Open them, move them, or delete them; History can also delete them for you.
  • Secrets are encrypted. Saved tokens and passwords are encrypted with a key protected by Windows, and are never written into those files in plain text.

The usage counts are stored without IP addresses, and the install number is scrambled before it is stored. They are used only to see how many people use the app, on which systems and versions, so we know what to build next.

This website

  • No cookies, no trackers, no analytics, no outside fonts.
  • The page asks GitHub's public API for the latest version number, and downloads come from GitHub Releases. GitHub sees those requests as it would for any visitor; see GitHub's privacy statement.
  • Your light or dark choice is remembered in your browser only.
