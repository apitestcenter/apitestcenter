Learn API testing, from zero

Free lessons on APIs, API testing and load testing — what each idea is, why it matters, and how to try it yourself in a few minutes.

These lessons take you from "what is an API?" to finding out why an API slows down under load. Each one explains an idea in plain words, shows real examples, and ends with something to try yourself — on a practice API that runs on your own computer, so you can't break anything and need no server of your own.

Nobody is expected to know the words already. When a lesson uses a term for the first time, it explains it; the glossary has them all.

How to follow along

The Try it boxes use APITestCenter, a free app for sending API requests and running load tests. Download it, or run npx apitestcenter ui if you have Node.js. It has a small practice API built in — a pretend shop with products, sign-in and orders. In the app it's written {{practiceApi}}, so {{practiceApi}}/products means "the practice shop's product list".

The ideas aren't tied to one tool: what you learn here works with any API and any testing tool.

A suggested path

  • New to APIs? Read 1 to 5 in order — about an hour, with the Try it boxes.
  • You use APIs, and want to test them well? Start at 8, and dip back into 4 and 6 when needed.
  • You need to load-test something this week? Read 15, 16 and 17, then 20 before you start.
