Send and check
A tour in six stops
01

Paste a URL. Press Send. Know it’s right.

Paste a URL or a whole curl command from your browser. Add checks — status is 200, has a total, matches the OpenAPI schema — so a fast-but-wrong answer still fails.

02

Sign in once. Every request uses the token.

Run a login first, keep its token as {{token}}, feed in users from a CSV. OAuth 2.0, OAuth 1.0, AWS, JWT, client certificates, NTLM — all there.

03

The same request, under real load.

Pick a preset — smoke, average day, stress, spike, soak — or shape your own. Response times and requests per second, live, as it runs.

04

An answer, not a spreadsheet.

“Meets your goals under this load” first — then the detail: where the time went, what broke first, how it compares with last week.

05

Arrange it for whoever reads it.

Twenty charts and numbers to drag and resize. One view for developers, one for managers. Export to Excel, HTML or JSON, or email a summary.

06

Never done this before? It teaches you.

A practice API built in, a one-minute tour, help on every term, and 20 free lessons on APIs, testing and load testing — from zero.

Questions
Is it really free?

Yes — everything is free during early access: requests, load tests, reports, the command line and the MCP server. Paid Pro and Team plans will come later; we’ll announce them here first.

Does it send my requests or results anywhere?

No. Requests go straight from your computer to the API you are testing, and results are plain files on your computer. There is no account. The app asks once whether you’d share anonymous usage counts — say no and nothing is sent. See the privacy page.

I use Postman. Can I bring my collections?

Yes — import Postman, Insomnia and Bruno collections, .http files (VS Code REST Client, JetBrains) and Hurl files with their folders, environments, auth and scripts (pm.test, pm.sendRequest run as they are), or an OpenAPI file, where every request also checks its answer against the spec.

I have never done load testing. Where do I start?

Open the app and choose “Try a simple request”. It uses a practice API built into the app, so you learn without touching a real system. The free lessons explain every idea from zero.

How much load can it make?

Up to 500 simulated users, or a fixed rate of up to 100,000 requests per second — limited mostly by your computer and network. The report tells you when the machine itself was the bottleneck.

Is it safe to load test any API?

Only test systems you own or have permission to test. A load test is real traffic; against someone else’s API it can look like an attack.

How do I report a bug or ask for a feature?

Open an issue on GitHub or email support@apitestcenter.com. For anything else, write to hello@apitestcenter.com.
