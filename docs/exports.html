Exports and sharing

Save a report as HTML, Excel, JSON, or a Zip of everything, send it by email, or produce JUnit for CI dashboards.

From a load-test report

The export bar above the report offers:

FormatGood for
HTMLOne page that opens in any browser, offline, and prints well. Follows your report view, starts with What happened in this run and suggested next steps, and has no scripts.
ExcelThree sheets — Overview, Result summary, and Second by second — for your own charts and records.
JSONThe full report. Open it again later with Open report, or feed it to your own tools.
Response JSONThe answer of the last Send.
ZipAll of the above in one file.

Share opens a ready-to-send email: a formatted summary for Gmail, Outlook on the web, or your mail app, with the files to attach. Copy formatted summary puts it on the clipboard to paste into any email or chat.

From a compare

Excel and Zip, plus sharing by email. See Compare APIs.

From a collection run

HTML, JUnit (one test case per request — Jenkins, GitLab, Azure DevOps, and GitHub test reporters read it), and JSON. See Run a collection.

What never goes into an export

  • Secrets. Auth appears as a type only (Bearer, Basic, API key), never the value.
  • Filled-in values. URLs appear as you wrote them, with {{variables}}, so tokens and ids from your environment don't leak.
  • Test data. Only the file name and the number of rows.
