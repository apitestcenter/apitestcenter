Results

Exports and sharing

Save a report as HTML, Excel, JSON, or a Zip of everything, send it by email, or produce JUnit for CI dashboards.

From a load-test report

The export bar above the report offers:

FormatGood for
HTMLOne page that opens in any browser, offline, and prints well. Follows your report view, starts with What happened in this run and suggested next steps, and has no scripts.
ExcelThree sheets — Overview, Result summary, and Second by second — for your own charts and records.
JSONThe full report. Open it again later with Open report, or feed it to your own tools.
Response JSONThe answer of the last Send.
ZipAll of the above in one file.

Response JSON appears only when the report has a Send answer to go with it.

Share

Share opens a menu:

EntryWhat it does
GmailOpens a panel with the files to attach, then a Gmail draft with the summary.
Outlook on the webThe same, for Outlook on the web.
Default mail appThe same, through your computer's mail program.
System shareHands the HTML and Excel files to your system's share sheet, where there is one. Otherwise it falls back to Default mail app.

Browsers can't attach files to an email for you, so the panel offers them to download first: HTML report, Excel, and Zip, with JSON and Response JSON under Also available. It also has:

  • Copy formatted summary — the Result, key numbers, response-time chart, goals, and checks (and the change against your reference run), ready to paste into any email or chat.
  • Email draft with report attached (.eml) — a file that Outlook, Apple Mail, and Thunderbird open as a ready draft with the HTML report already attached. Add recipients and send.

Open Gmail (or Outlook on the web, or your mail app) then starts the email.

From a compare

The export bar above the compare results offers:

FormatGood for
ExcelSheets Side by side (the key numbers and which API was best on each), Over time (each API's p95, requests per second, error rate, and users, second by second), Result summary (each API's result in plain words), and one sheet per API with its own summary. Needs at least two APIs.
JSONThe whole compare. Open it again later with Open report.
Response JSONsA zip with each API's Send answer. Available when at least one API has one.
ZipThe Excel, the JSON, and the Send answers in one file.

Share has the same four entries. The panel offers Download Excel and Download Zip to attach; the email lists each API and its key numbers, with the best one named. System share hands over the Zip. See Compare APIs.

From a collection run

HTML, JUnit (one test case per request — Jenkins, GitLab, Azure DevOps, and GitHub test reporters read it), and JSON. See Run a collection.

What never goes into an export

  • Secrets. Auth appears as a type only (Bearer, Basic, API key), never the value.
  • Filled-in values. URLs appear as you wrote them, with {{variables}}, so tokens and ids from your environment don't leak.
  • Test data. Only the file name and the number of rows.
