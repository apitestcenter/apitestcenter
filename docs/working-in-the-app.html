Working in the app

The window, request tabs, the command palette, keyboard shortcuts, zoom and density, light and dark themes, environment colours, the Help panel and tour, and notifications when a run ends.

Finding your way

  • The top bar has the open project's name (click it for Home), the search box — Search, run or jump to anything (the command palette) — and, when an environment is chosen, its name.
  • The sidebar on the left has the pages: Home (your projects), Test API, Run collection, Compare, History, and Open report — and, at the bottom, Trash (deleted requests, kept 30 days).
  • The status bar along the bottom shows whether the engine is ready (and the k6 version), and has Import, Cookies, Certificates and Mock server; on the right, zoom, density, the theme, Help, and the version — click it for About (updates, and where your files are).

Projects

A project is a folder of its own: its saved requests, environments, load test history, versions and Trash, as plain files. Keep each API — or each client, or each team — in its own project, and keep a project's folder in Git if you like (secret values are never in its files).

Home (top of the sidebar, or the project's name in the top bar) lists your projects, with how many requests and environments each has and, if its folder is in a Git repository, the branch.

ToDo this
Make a projectNew project, give it a name, then Create and open. It goes in Documents/APITestCenter Projects/<name> — or Choose… another folder.
Use a folder you already haveOpen folder… — a project folder from a colleague or a Git repository, or an empty folder
Switch projectClick its card. The app reopens on that folder in a second or two.
Rename, or take one off the list⋯ on its card. Taking it off the list leaves its folder and files where they are.

My workspace is the folder the app has always used; it's always on the list. Open tabs and the chosen environment are kept per project; theme, zoom and density are the same everywhere. Projects are a desktop-app feature — with the command line, pick a folder with --data (see CLI and CI).

Request tabs

Each request you open on Test API gets a tab of its own, above the address bar, with its method and name. A tab keeps its request and its last answer, so you can switch between several APIs and come back to each as you left it.

  • Opening a saved request opens its tab — or switches to it, if it's open already.
  • + at the end of the tabs starts a new request.
  • ✕ (or a middle click) closes a tab. If it has changes you haven't saved, the app asks first.
  • A dot on a tab means its saved request has changes you haven't saved.

Open tabs come back when you restart the app; their answers don't — send again to see them.

The command palette

Press Ctrl+K (⌘K on a Mac) anywhere, or click the search box in the top bar. Type a few letters of what you want — letters can be anywhere in the name, so ord finds Orders API / List orders. Use ↑ and ↓ to move, Enter to run, Esc to close.

Light and dark

The theme button in the status bar moves between System, Light and Dark each time you click it; Theme: in the command palette picks one directly. System follows your computer's setting.

Zoom and density

Make everything bigger or smaller with − and + in the status bar, or Ctrl +, Ctrl − and Ctrl 0 (back to 100%) — ⌘ on a Mac. Comfortable and Compact (next to the zoom) change how tall the rows of saved requests and the tabs are. The app remembers both.

Environment colours

The environment's name tells the app how careful to be:

Name containsWhat you see
Production, prod, liveA red line across the top of the window, a red name in the top bar, and a note under the address. Before a request that can change data (anything but GET, HEAD and OPTIONS) and before a load test, the app asks.
Staging, stage, UAT, preprod, QAAn amber line and an amber name.
anything elseNo colour.

Rename an environment under Manage environments (the gear next to the environment picker) to change its colour.

The welcome card

When you first open Test API, the right-hand panel shows New here? Start with something safe to test. It uses the practice API built into the app, so nothing real is touched:

ChoiceWhat it does
Try a simple requestFills in {{practiceApi}}/products with two checks. Press Send.
Try a sign-in exampleAdds two requests to a Practice collection: Sign in, and My orders, which signs in first and uses the token. See Chaining.
Take the 1-minute tourStarts the tour (below).

The practice choices are greyed out while the engine is offline.

The card disappears once you send a request. To hide it for good, press ✕ in its corner. To bring it back, open Help and choose Show the getting-started guide on Test API again.

The tour

Take the 1-minute tour points out, one at a time: where the request goes, what to send, trying it once with Send, testing it under load, reading the result, History, and Help. Use Next and Back (or → and ←), Done on the last step, and Skip tour to leave early. Start it from the welcome card, the Help panel, or the command palette.

The Help panel

Click Help in the status bar. The panel has:

  • Take the 1-minute tour;
  • Show the getting-started guide on Test API again — brings back the welcome card;
  • Share anonymous usage counts — on or off. Show exactly what would be sent shows the data. Only the desktop app sends these; see Privacy and your data;
  • About APITestCenter — version, updates, your files;
  • a link to this user guide;
  • the glossary — every word the app uses, in plain language, grouped into Setting up a test, Reading results, and About the app. Type in What does … mean? to search it.

Notifications

When a load test or a compare ends, the app tells you:

  • In the app, a short message appears in the bottom-right corner.
  • When the app is not in front, the window or tab title changes — for example to ✓ Load test finished, or with ✕ when the run failed — until you come back.
  • A system notification, if you turned it on with Notify me when done on a running test. Click the notification to bring the app back. Notifications are only shown when you're looking at something else.

While a run is going, the title shows the time left, such as 0:42 left. More: Load tests.
