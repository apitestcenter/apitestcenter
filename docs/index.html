Guide

The APITestCenter guide

Everything the app does, in plain words — from your first request to load tests, collection runs, and CI.

New to APIs or load testing? Learn has free lessons from zero — what an API is, how to test one, and how to read a load test — each with something to try in the app.

APITestCenter sends requests to your API, load-tests it, and tells you in plain language whether it is fast enough and holds up. Everything runs on your computer; nothing is uploaded.

New here? Start with these

  1. Getting started — install, send your first request, run your first load test. About 5 minutes, using the practice API built into the app.
  2. Reading the report — what every number means and how the app decides pass or fail.
  3. Load tests — presets, simulated users or requests per second, and goals.
